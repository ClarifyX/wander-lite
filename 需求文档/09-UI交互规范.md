# UI 交互规范

**1.0.1 / 1.0.2 已覆盖本文。实现请读 `1.0.1.txt` 与 `1.0.2.txt`。**

下文仅保留未改的约束。色板、三档、ChatGPT 对话条以 1.0.1 为准；DeepSeek 与四周留缝以 1.0.2 为准。

## 仍有效

- 输入框、按钮有可见文字或 aria-label
- 地图容器 `aria-label="漫游地图"`
- 抽屉 `aria-label="对话抽屉"`，拖拽条可键盘/指针操作
- 不要只用颜色表示错误
- 动效克制，不要 Lottie
- 文案不要出现：「智能导航」「一键规划旅游行程」「Powered by GPT」

## 已作废（1.0）

- 左右分栏
- 纸色 / 苔绿 / 陶土手册风
- 助手消息上的「向导 / 校验」彩色大标签（改成 ChatGPT 左对齐正文）
- 贴边全宽 Bottom Sheet（1.0.2 要求四周留缝悬浮卡片）
- OSM 彩色标准瓦片当主底图
