0. 这个「框」叫什么
--------------------
标准名称：**Bottom Sheet（底部抽屉）**

也叫：底部面板 / 可拖拽抽屉。不要写成「弹窗」「对话框」「侧边栏」。

代码建议：
  #sheet          整个抽屉
  #sheet-handle   顶部中间那根灰色拖拽条
  #sheet-messages 对话区
  #composer       底部输入条（三种高度下都在）
  js/sheet.js     三档吸附、拖拽、键盘顶起


1. 改了什么（相对 1.0）
------------------------
旧：桌面左右分栏（左聊天，右地图）；纸色 / 墨色 / 苔绿。
新：全屏地图为底，对话放在底部抽屉里；北欧极简浅灰；聊天长得像 ChatGPT 移动端。

参考（用户提供，实现时对照气质，不要抄苹果商标/图标）：
  - 苹果地图：全屏地图 + 毛玻璃底部抽屉 + 三档高度
  - ChatGPT App：右气泡用户、左纯文本助手、底部胶囊输入条


2. 地图色彩（强制）
------------------
瓦片（北欧极简浅灰，CartoDB Positron / light_all）：

  https://{s}.basemaps.cartocdn.com/light_all/{z}/{x}/{y}{r}.png

attribution 必须保留，例如：
  © OpenStreetMap © CARTO

禁止再用默认 OSM 彩色标准瓦片当主底图。
禁止高德 / 谷歌 / Mapbox。

页面与抽屉配色（浅灰极简，不要苔绿手册风）：

  --bg          #f2f2f7          系统浅灰（抽屉背后若露边）
  --sheet       rgba(255,255,255,0.86)
  --sheet-solid #ffffff
  --hairline    rgba(60,60,67,0.12)
  --text        #1c1c1e
  --text-2      #8e8e93
  --user-bubble #e9e9eb          用户气泡（ChatGPT 浅灰）
  --fill        #f2f2f7          输入条底
  --accent      #007aff          仅发送按钮、定位按钮；克制使用
  --handle      #c7c7cc

字体：系统 UI 字体（-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", sans-serif）
不要衬线标题、不要纸纹、不要陶土强调色。

毛玻璃（苹果那层感觉）：
  background: rgba(255,255,255,0.78);
  backdrop-filter: saturate(180%) blur(28px);
  -webkit-backdrop-filter: saturate(180%) blur(28px);
  抽屉顶角圆角 20～28px；轻阴影。


3. 整体结构（所有宽度都这样，不再左右分栏）
------------------------------------------
层级从底到顶：

  1) #map          100vw × 100vh，Leaflet 全屏
  2) 地图浮钮      右下、贴在抽屉上方：定位到我、可选图层
  3) #sheet        底部抽屉，盖住地图下半（或几乎全屏）

宽屏桌面也保持「地图铺满 + 底部抽屉」，不要退回左右栏。
抽屉在宽度 > 768px 时 max-width: 480px，水平居中或靠左 16px 悬浮，更像 iPad 地图；高度逻辑仍是三档。


4. 三档高度 = 用户说的三个「页面」
----------------------------------
这不是三个路由，是同一个底部抽屉的三个吸附点（snap points）。
用 transform/height + 手势，不要做三套 HTML 页面。

档位名           用户叫法     高度（含安全区）
-------------------------------------------------
half             页面 1       约 48% 视窗高（默认，刚进入）
expanded         页面 2       约 92% 视窗高（留顶 8% 仍能瞥见地图）
collapsed        页面 3       只露出：拖拽条 + 输入条
                              约 88px + safe-area-inset-bottom

页面 1（half，默认）
  - 上半：地图可见、可拖可缩放
  - 下半：抽屉里是人和 AI 的对话 + 最底下输入条
  - 刚打开 App 就停在这一档
  - 对话区可滚动；输入条钉在抽屉底部

页面 2（expanded）
  - 抽屉几乎拉满
  - 用来回看长对话、路线预览卡、点【确认 / 重新生成】
  - 顶部仍保留细拖拽条，可下拉回 half / collapsed
  - 地图几乎被挡住，但不要卸载地图

页面 3（collapsed）
  - 地图几乎全屏
  - 底部只剩输入条（和细拖拽条）
  - **用户仍可点输入框、打字、发送**
  - 键盘弹起时：输入条贴在键盘上方，不要被挡住
  - 发送成功（或点发送）后：抽屉自动弹回页面 1（half），以便看到回复
  - 点输入框获得焦点时：建议也弹到 half，避免对着全屏地图打字看不见历史；若与「最小态也能输入」冲突，以「最小态可输入」为准，发送后再升到 half

吸附规则：
  - 拖拽条、抽屉顶空白可拖；对话列表滚动不要抢垂直拖（只有滚到顶再下拉才关抽屉）
  - 松手落到最近档；快速甩动跟手势方向进相邻档
  - 点击拖拽条：half ↔ expanded 切换（可选，有则更好）
  - 地图拖拽缩放与抽屉拖拽互不误伤：从地图上滑不要带动抽屉


5. 抽屉内部（上到下）
--------------------
  [ 灰色胶囊拖拽条 36×5 ]
  [ 可选：一行小标题「轻漫游」+ 设置（Key）  仅 half/expanded 显示 ]
  [ 消息列表，ChatGPT 风格 ]
  [ 输入条，始终在抽屉最底 ]

阶段 2 的【加载示例路线】：放在 half/expanded 的标题行或输入条左侧「+」菜单里，不要做成巨大主按钮破坏极简。


6. 对话 UI（跟 ChatGPT App，不是气泡聊天室堆满标签）
----------------------------------------------------
用户：
  - 右对齐
  - 浅灰圆角气泡 #e9e9eb
  - 字号约 16px，左右 padding 14px，上下 8px
  - 不要头像

助手：
  - 左对齐
  - **不要气泡**，白底/毛玻璃上直接排版（ChatGPT 那种）
  - 长文可 Markdown：小标题、列表
  - 路线预览是一张浅灰描边卡片，嵌在助手消息下面
  - 预览卡下：【确认并画到地图】【重新生成】做成小字按钮，不要大色块 CTA

系统/错误：
  - 居中或左侧灰色小字，不要大红条

输入条（三种高度都在，长得像 GPT 底栏 + 苹果搜索条）：
  - 胶囊形，浅灰底 #f2f2f7，圆角满
  - 左：+ （展开：示例路线、API Key 设置）
  - 中：textarea，placeholder「说说你想怎么逛…」
  - 右：有字时显示蓝色圆形发送；空时可用灰色箭头/占位（语音识别 1.0.1 不做，图标可画但不接语音）
  - Enter 发送，Shift+Enter 换行
  - collapsed 态输入条左右留 12px，看起来像悬浮在地图上的搜索框


7. 地图浮钮
------------
抽屉右侧上方（随抽屉高度上移，始终露在地图上）：
  - 定位到我（Geolocation，失败则静默）
  - 不要默认 Leaflet 左上大 zoom 控件；改成右下细按钮或保留 +/- 但样式改成白方圆角，像苹果图层钮

有路线后：地图 fitBounds 时加 paddingBottom = 当前抽屉高度，路线不要藏到抽屉下面。
抽屉高度变化要 map.invalidateSize()，并更新 padding。


8. API Key
----------
不要顶栏大表单。放进输入条「+」或抽屉标题右侧齿轮。
未填 Key 时，第一次点发送弹出轻量设置层（仍在抽屉内），不要跳页。
规则仍是：只进内存，不写 localStorage。


9. 阶段 1 就要做成这套壳
------------------------
阶段 1 验收改成：
  - 全屏浅灰 Carto 地图可拖可缩放
  - 底部抽屉默认 half（页面 1），能拖到 expanded（页面 2）和 collapsed（页面 3）
  - collapsed 能聚焦输入框
  - 消息区有一句开场白（ChatGPT 左对齐纯文本）
  - 无 LLM、无路线点

阶段 2：示例路线画在地图上；抽屉保持可拖。
阶段 3：闸门卡画在抽屉消息流里；确认后画地图，建议自动把抽屉降到 half 或 collapsed，让用户看清路线。


10. 动效
--------
抽屉跟手；松手 280～360ms cubic-bezier(0.22, 1, 0.36, 1) 弹到档位。
不要弹跳过度、不要全屏动画库。


11. 明确不要
------------
  - 左右分栏布局
  - 纸色苔绿陶土手册风
  - OSM 标准彩色瓦片当主底图
  - 把 Bottom Sheet 做成不能拖的固定底栏
  - collapsed 时禁用输入
  - 发送后还停在 collapsed 让用户看不到回复
  - 三个真页面 / 三套路由
