# 阶段 1：PWA 基础壳

## 目标

浏览器打开就是苹果地图那种结构：全屏浅灰 Leaflet 地图，底部一块可拖的 **Bottom Sheet（底部抽屉）**。默认停在半高（页面 1），里面是 ChatGPT 风格对话壳（还不能生成路线）。PWA 可安装。没有 LLM，没有路线点位。

布局与三档交互以 `1.0.1.txt` + `1.0.2.txt` 为准：**不要左右分栏，不要贴边全宽抽屉**。抽屉四周与屏幕有间隙，四角大圆角。

## 必须产出的文件

- `index.html`
- `manifest.json`
- `service-worker.js`
- `css/app.css`
- `js/app.js`（本阶段只做布局与空聊天壳、SW 注册）
- `js/sheet.js`（三档抽屉：half / expanded / collapsed）
- `js/map.js`（初始化 Carto light_all 地图）
- `icons/icon-192.png`、`icons/icon-512.png`

## 页面结构（1.0.2，全屏地图 + 四周留缝悬浮抽屉）

```
┌──────────────────────────────────────┐
│            全屏浅灰地图               │
│                          [定位]      │
│   ╭──────────────────────────────╮   │  ← 左右约 10px 缝
│   │          ── 拖拽条           │   │
│   │     对话（ChatGPT 风格）     │   │  页面1 half
│   │  [+]  说说你想怎么逛…  [发]  │   │  页面2 四边都有缝
│   ╰──────────────────────────────╯   │  页面3 扁卡片仍留缝
│        ↑ 底缝 + 安全区               │
└──────────────────────────────────────┘
```

三档吸附见 `1.0.1.txt`，悬浮留缝见 `1.0.2.txt`。宽屏卡片 max-width 480px，仍然四周留缝。

## 地图要求

- `#map` 必须有明确高度，否则 Leaflet 灰图。
- `L.map('map', { zoomControl: true, scrollWheelZoom: true, dragging: true })`
- `invalidateSize()` 在首屏和窗口 resize 时调用。
- 无 Marker、无 Polyline。
- 空态遮罩不要挡住拖拽：用 `pointer-events: none`，或仅覆盖文案区域。推荐遮罩可关、地图始终可拖。

## PWA 要求

`manifest.json` 最小字段：

```json
{
  "name": "轻漫游 · 本地灵感探索器",
  "short_name": "轻漫游",
  "description": "对话式家门口短途漫游灵感探索器",
  "start_url": "./",
  "scope": "./",
  "display": "standalone",
  "background_color": "#f2f2f7",
  "theme_color": "#f2f2f7",
  "lang": "zh-CN",
  "icons": [
    { "src": "icons/icon-192.png", "sizes": "192x192", "type": "image/png", "purpose": "any" },
    { "src": "icons/icon-512.png", "sizes": "512x512", "type": "image/png", "purpose": "any maskable" }
  ]
}
```

Service Worker：

- `install` 时 `cache.addAll` 本地静态资源（不要 cache 整个 OSM 域名）。
- `fetch`：同源请求 cache-first，失败回网络；CDN（leaflet）network-first 或 cache-first 均可。
- 更新策略简单即可：`skipWaiting` + `clients.claim` 可以要，注意开发时硬刷新。

`index.html` head：

- `<link rel="manifest" href="./manifest.json" />`
- `<meta name="theme-color" content="#f2f2f7" />`
- `<meta name="apple-mobile-web-app-capable" content="yes" />`
- `<link rel="apple-touch-icon" href="./icons/icon-192.png" />`

## 明确禁止

- 禁止本阶段出现 DeepSeek / Claude 请求。
- 禁止本阶段加载路线 JSON 打点（那是阶段 2）。
- 禁止登录、路由框架。
