# 数据协议

所有路线（示例 JSON 与 DeepSeek 输出）必须能被同一套 `renderRoute` / `parse` 消化。

## JSON Schema（逻辑）

```json
{
  "title": "string，路线短名",
  "theme": "string，主题",
  "city": "string",
  "mode": "walk | cycling | trail",
  "durationHours": "number，1～3",
  "distanceKm": "number，估算",
  "summary": "string，80字内，为什么适合",
  "stops": [
    {
      "name": "string",
      "lat": "number，WGS84",
      "lng": "number，WGS84",
      "stayMinutes": "number，可选，默认 15",
      "intro": "string，点位介绍，40～80字",
      "tips": "string，可选，路面/开放时间/注意"
    }
  ]
}
```

约束：

- `stops.length`：4～8（解析器放宽到 2～12，超出则失败）
- `lat` 中国城市大致 18～53，`lng` 73～135，超出视为非法（防止 0,0 或幻觉到国外）
- 禁止缺 name / lat / lng / intro

## 模型输出包装

助手可见文本 + **唯一** fenced block：

````
先用两三句话说明这条路线。

```json
{ ... }
```
````

前端正则建议：

```js
function extractJson(text) {
  const fences = [...text.matchAll(/```(?:json)?\s*([\s\S]*?)```/gi)];
  if (!fences.length) return null;
  return fences[fences.length - 1][1].trim();
}
```

不要用贪婪正则一次吃掉全文。取最后一个 fence，避免模型先写示例再写正式稿时拿错。

若没有 fence，再尝试抓第一个 `{` 到最后一个 `}` 的子串；仍失败则报错。

## 方式枚举与中文

| mode | 中文 |
| --- | --- |
| walk | 老街区漫步 |
| cycling | 城市骑行 |
| trail | 公园轻越野 |

未知 mode 时预览显示原文，地图仍可画。

## 校验失败不要静默

把失败原因留给 UI，不要 `console.log` 了事。
