# 产品定义

## 产品名

**轻漫游**（对外英文可写 Wander Lite）

副标题：AI-Native 城市轻漫游灵感探索器

## 一句话

把年轻人说不清的「家门口短途」收成一条可走、可骑、人少、有氛围的城市路线，并画在开源地图上。

## 场景边界

| 做 | 不做 |
| --- | --- |
| 城市老街区漫步 | 跨城 / 多日游 |
| 城市骑行 | 机票、酒店、签证 |
| 公园轻越野 | 专业户外装备与导航 |
| 1～3 小时、家门口 | 穷游攻略、网红打卡清单 |
| 对话挖掘模糊偏好 | 「起点终点时长」表单出路线 |

关掉对话 / 推荐逻辑后，右侧必须是空地图。地图是对话结果，不是主产品。

## 目标用户

- 住在大城市的年轻人
- 周末下午、下班后傍晚
- 不想去外滩 / 田子坊 / 西湖断桥 / 南锣鼓巷这类过曝点
- 说得出氛围（安静、有烟火气、看老建筑），说不出地点清单

## 产品负责人要讲清的三件事

1. **用户说不清要什么**，所以主交互是挖掘，不是参数表。
2. **AI 编排，人做出行决策**。闸门在初稿之后、当真走之前。
3. **地图是生成物**。验证方法：不跑生成，右边是空的。

## 成功标准（Demo 可验证）

1. 用户用一句模糊话开始，Agent 能追问补齐约束。
2. 生成结果是约定 JSON：路线名、主题、带经纬度的点位、顺序、短介绍。
3. 地图自动打点连线，点击点位能看介绍。
4. 未确认前地图不渲染新路线；用户可重新生成。
5. 浏览器可直接使用，可安装为 PWA。
6. 公开站点不内置 Key；使用者自行填写 DeepSeek API Key。
