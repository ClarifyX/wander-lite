# 验收清单

实现 Agent 每阶段结束必须自检。全部通过才算完成。

## 阶段 1

- [ ] 存在 `index.html`、`manifest.json`、`service-worker.js`
- [ ] 全屏 Carto `light_all` 浅灰地图，可拖拽、滚轮缩放（**不是**左右分栏）
- [ ] Bottom Sheet 默认 half（页面 1）：上地图、下对话；**左、右、下能看见地图缝**，四角大圆角
- [ ] 上拉到 expanded（页面 2，四边留缝），下拉到 collapsed（页面 3，扁卡片仍留缝）
- [ ] collapsed 仍能聚焦输入框；发送后抽屉回到 half
- [ ] 对话区 ChatGPT 风格：用户右气泡，助手左纯文本
- [ ] 无 Marker / 无路线数据 / 无 DeepSeek 或 Claude 请求
- [ ] `http://127.0.0.1:xxxx` 打开（非 file://）
- [ ] Application → Manifest 无报错；SW 状态为 activated
- [ ] 390px 宽不断版，地图有高度，输入条不被安全区挡住

## 阶段 2

- [ ] 【加载示例路线】按钮可见
- [ ] 使用 `data/sample-route.json`，字段与 `需求文档/sample-route.json` 兼容
- [ ] 点位数量与 JSON 一致，有折线
- [ ] 点击点位弹出名称与介绍
- [ ] 重复点击不叠加重复图层
- [ ] 仍无 LLM 调用

## 阶段 3

- [ ] Key 输入框存在；刷新后 Key 消失
- [ ] 代码仓库全文搜不到真实 sk- Key
- [ ] 未填 Key 发送有提示，且仍可用示例路线
- [ ] 有 Key 时 Agent 会追问，一次回复里问题不超过 2 个（抽测 1 轮）
- [ ] 槽位齐后回复含 json 代码块
- [ ] 正则抽取 + parse 失败有可见错误，地图不乱画
- [ ] 抽出成功后出现【确认并画到地图】【重新生成】
- [ ] 未点确认前，新路线不上图
- [ ] 确认后才打点画线 fitBounds（padding 避开当前抽屉高度 + 留缝）
- [ ] 请求为 DeepSeek：`Authorization: Bearer`，打到 `api.deepseek.com` 或同源 `/api/chat`
- [ ] 无 `api.anthropic.com` / `anthropic-*` 残留

## 阶段 4

- [ ] README 含本地运行、Pages 部署、自备 Key 说明
- [ ] 所有资源相对路径，适合 `https://user.github.io/repo/`
- [ ] `docs/产品架构.md` 写清定义、流程、闸门、取舍
- [ ] 390px 宽度可完成「加载示例路线」
- [ ] 长途需求被拒绝（有 Key 时测；无 Key 时在文档写明测试步骤）

- [ ] PWA Demo 可安装（Pages 或 localhost）
