# 阶段 2：静态路线验证

## 目标

不接大模型。用一份写死的 JSON 证明：前端能打点、画线、弹介绍。验证的是 **地图渲染逻辑**，不是 AI。

## 必须做

1. 把 `需求文档/sample-route.json` 复制到 `data/sample-route.json`（字段不要改名）。
2. 在抽屉标题行或输入条「+」菜单里提供 **【加载示例路线】**（half / expanded 可见即可）。
3. 点击后 `fetch('./data/sample-route.json')`，校验后调用 `map.renderRoute(route)`。`fitBounds` 要加当前抽屉高度的 bottom padding。
4. 隐藏地图空态遮罩。
5. 聊天区出现一条「系统」消息，附路线摘要（标题、时长、点位名称列表）。本阶段 **没有** 确认/重新生成闸门（闸门是阶段 3 的）。示例路线可以直接上图，因为它是开发者写死的可信数据。
6. 再点一次按钮：先 `clearRoute()` 再渲染，不要叠加两套 Marker。

## 地图渲染规格

函数建议：

```
createMap(domId)
renderRoute(route)  // 清旧 → 逐点 marker → polyline → fitBounds → 点 popup
clearRoute()
```

Marker：

- 每个 `stops[]` 一个点
- Popup HTML：`名称` + `介绍` + 可选 `停留` + `提示`
- 点击 Marker 打开 Popup

Polyline：

- 按 `stops` 顺序连接
- 颜色用深灰 `#3a3a3c` 或低饱和蓝灰，weight 3～4，opacity 0.85（浅灰底图上不要用鲜绿）

`fitBounds` 留 padding。若只有 1 个点则 `setView(latlng, 15)`。

## 本阶段仍禁止

- DeepSeek / Claude / 任何 LLM
- 把示例路线假装成模型生成（文案写「示例路线，用于验证地图」）

## 手工测试

1. 打开页面，地图可拖。
2. 点【加载示例路线】，视野跳到杨浦滨江一带。
3. 看到 6 个点、一条线。
4. 逐个点击点，弹窗中文介绍可读。
5. 缩放、拖拽不丢点。
6. 再点按钮，点线数量不变（没有重复）。
