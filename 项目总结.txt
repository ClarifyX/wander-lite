个人项目｜AI-Native 城市轻漫游灵感探索器（PWA，Vibe Coding 搭建）
================================================================

一句话
------
面向年轻人「家门口短途漫游」：用对话把模糊偏好挖清楚，生成 1～3 小时可走/可骑路线，渲染到开源地图。浏览器直接用，可安装成 PWA。


做什么 / 不做什么
----------------
做：城市老街区漫步、城市骑行、公园轻越野；对话收敛偏好；短途路线；Leaflet 开源地图；PWA。
不做：长途旅行规划、酒店机票、导航导航 App、网红打卡清单、表单填参出路线。


为什么做
--------
用户往往只说得出「松弛、人少、别太累」，说不出地点。大众旅游 App 推远途网红点，地图 App 假设你已经知道去哪。
本产品主路径是「对话挖掘 → 结构化路线 → 人确认 → 地图呈现」，地图是结果载体，不是主功能。


目标用户
--------
城市年轻人，周末下午 / 傍晚，家门口 1～3 小时微漫游。


核心体验
--------
1. 用户说一句模糊想法（例：周末市区骑行 2 小时，看老厂房，避开网红，路尽量平）。
2. Agent 主动追问，一次最多 2 问，补齐：城市、方式、时长、起点片区、风格等。
3. 输出 JSON 路线（点位含经纬度与介绍）。
4. 人工闸门：【确认】才画地图，【重新生成】再走一轮。
5. 地图打点、连线、点击弹窗介绍。


四阶段（实现必须按此顺序，不可跳步）
----------------------------------
阶段 1  PWA 基础壳（视觉以 1.0.1 + 1.0.2 为准）
        index.html + manifest.json + service-worker.js
        全屏 Carto 浅灰地图 + 四周留缝悬浮抽屉（Bottom Sheet）三档
        可安装 PWA
        无 LLM、无路线数据

阶段 2  静态路线验证
        内置固定 JSON 样例 +【加载示例路线】按钮
        打点、画线、点击点位弹介绍
        仍不接入大模型

阶段 3  接入 DeepSeek
        页面填 DeepSeek API Key（仅内存，不硬编码、不写 localStorage）
        Agent 追问补齐偏好 → 输出 JSON
        前端正则抽 JSON，捕获解析异常
        预览闸门：确认 / 重新生成；确认后才渲染地图

阶段 4  测试 + GitHub Pages 部署
        本地走通全流程
        公开页使用者自行填 Key 才能调用 AI

技术要点
--------
- 纯前端静态站，适合 GitHub Pages
- 地图：Leaflet + CartoDB light_all 浅灰瓦片（无地图 Key）
- UI：苹果地图式悬浮 Bottom Sheet（四周留缝、四角圆角；半高 / 全开 / 只剩输入条）+ ChatGPT 对话条
  详见 需求文档/1.0.1.txt 与 需求文档/1.0.2.txt
- 模型：DeepSeek Chat Completions（`deepseek-chat`）
  Header：Authorization: Bearer <Key>
  GitHub Pages 若遇 CORS，用本地 server.py 同源反代（不存 Key）
- API Key 只存在内存，刷新即丢失
- 禁止把 Key 写进代码或提交到 Git


人机协同（产品决策）
--------------------
AI：从自然语言抽约束、追问、编排路线 JSON。
人：补充生活事实（从哪出发）、决定接不接受这条路。
闸门位置：路线初稿之后、当真走之前。再早会变成表单，再晚会把幻觉路线直接当出行方案。
